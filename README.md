# Little Talk

Little Talk is an original, responsive messaging-app prototype. It runs locally in your browser and saves demo data on this device.

## Run it

Open `index.html` in a browser, or serve this folder with any static file server. No build step or package install is needed.

## Try it

- Search conversations, or filter by unread messages and favorites.
- Send and search messages, reply to, edit, react to, star, or delete your own messages.
- Create one-to-one and local group conversations.
- Pin, mute, archive, restore, favorite, or mark conversations unread.
- Share short local status updates and browse the demo updates feed.
- Attach photos and audio, or record a voice note where microphone permissions are available.
- Save demo voice/video call activity to the call history. Calls are not connected.
- Select chats and save one message to all of them at once.
- Edit your local profile, switch to evening colors, and export or import a JSON backup.
- Use **Reset demo** to restore starter conversations and settings.

Conversation data is stored in this browser's local storage. Bulk messages only appear in the selected demo chats on this device. Status updates expire after 24 hours. This prototype does not connect to WhatsApp or other messaging services, other devices, real accounts, live voice/video calls, end-to-end encryption, or a server. It is not a WhatsApp clone and uses its own name and visual design.
